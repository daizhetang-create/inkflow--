## 主方向：Return Gate

它把时代新问题、可演示动作和跨场景内核叠在同一条 30 秒流程里。它不是程序员小插件，因为编程只是最清晰的异步中断样本；真正被保存的是 `intent + nextAction`，阅读、冥想与普通工作使用完全相同的状态机和回流握手。若真人验证显示 AI 间隙不高频，仍可将同一内核转向主动偏航救援，而不是推倒技术架构。

## 备选方向：Drift Rescue

无需任何 Agent 集成，跨人群更强，可成为主产品的永远可用入口。它没有天然完成信号，也更依赖用户在偏航时想起墨流，因此不作为首个故事。

## 高风险实验：Return Protocol

把 checkpoint/complete/return 定义为可由 Codex、Claude Code、Cursor、浏览器扩展消费的开放事件协议。若生态成立，壁垒最大；但本轮只实现本地 adapter interface 和 simulation/manual adapter，不公开声称外部集成。
