## 主要切口

**高频使用 AI Web Coding / Vibe Coding 的个人创造者。**

他们一天多次经历“Prompt 发出—Agent 执行—几十秒到数分钟空窗—完成后需要接管”。痛点可在一个浏览器页面中真实模拟，创始人自己就是高密度用户，社区传播语言明确：“AI 在生成时，别丢掉你回来后的第一步。”这一切口不是产品终点，而是最容易验证 attention continuity 的实验室。

## 备选切口

**同时运行多个 Agent 的高频异步工作者。**

价值与支付意愿更高，但需要 Codex/Claude/Cursor 等 adapter、桌面通知和多任务协调，工程与权限风险较大。vNext 保留 adapter 接口和多会话数据结构，但不伪装已集成。

## 暂不首发

- 全民注意力：问题宽、竞争拥挤、很难在一秒内解释独特性。
- 阅读/冥想：适合作为机制迁移测试，不再作为上位定义。
- ADHD：真实需求强，但必须进行更谨慎研究、无障碍与医疗合规评审。
- 低能量人群：进入“低能量回流”模式设计，不做独立市场承诺。
