# N — “墨流”品牌语义重审

## “墨”与“流”

- **墨是**：人在离开前主动留下的一笔最小、可持久、可取回的意图痕迹。
- **墨不是**：墨水动画、书法审美、暖纸背景或阅读专属符号。
- **流是**：注意力可以暂停、绕行、恢复，但仍保留去向的连续运动。
- **流不是**：无休止高效、永不分心、长时间停留或“默默流走”。
- **墨流作为名词**：一套注意力连续性协议。
- **作为动作**：离开前把下一步留下，回来时接回。
- **作为系统**：管理 Active/Waiting/Drift/Return 的 local-first 状态层。

中文“墨流”能支持 AI Coding、阅读、冥想和工作，因为“墨”被定义为意图痕迹，不是书；“流”被定义为可恢复连续性，不是计时。英文 **Inkflow** 保留诗性，但单独使用不够准确，需要品类副标题。

## 三套语义方向

### A. 墨流 · 注意力连续性（主方向）

- 品类：**Attention continuity tool / 注意力连续性工具**。
- 核心表达：**离开前留下一步，回来时接回它。**
- 语气：具体、温和、工程可信。
- 优点：跨场景、与核心机制直接一致。
- 风险：“连续性”略抽象，必须靠 30 秒体验解释。

### B. Inkflow Return · 人机协作回流层（备选）

- 品类：**Human–agent return layer**。
- 核心表达：**AI 在生成，别丢掉你回来后的第一步。**
- 语气：面向开发者、当下、可传播。
- 优点：窄门极清晰。
- 风险：品牌可能被锁死在程序员插件。

### C. 墨流 Relay · 状态接力协议（实验）

- 品类：**Attention handoff protocol**。
- 核心表达：**把任务交给 AI，也把下一步交给未来的自己。**
- 语气：系统级、协议化。
- 优点：适合 adapter/生态。
- 风险：面向普通用户过于技术。

## 资产决定

- 名称与中英文保留，采用 A；首场景文案借用 B，但不改产品上位定义。
- 旧书本圆环 Logo 不进入 vNext 主界面；它过度绑定阅读和计时。
- 新标记不画墨滴/书本，而由“两个断开的端点在接回时合成一条线”构成。
- 12 秒开场作为 legacy 品牌影片保留，不作为 vNext 首次使用门槛。
