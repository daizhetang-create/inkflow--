# G — 产品概念宇宙

| # / 概念 | 一句话定义 | 第一用户 / 首次场景 | 核心动作与反馈 | 为什么现在 / 为什么不是 Forest | 次日理由 | 最大风险 | 最小可验证原型 |
|---|---|---|---|---|---|---|---|
| 1. **Return Gate 回流门** | 浏览器里把一次 AI 等待变成可恢复连接 | Vibe Coder；发出 Codex 任务后 | 写下一步，AI/计时完成后穿过“回流门”；断线合拢成实线 | 异步 Agent 新增了等待状态；成功单位是回流，不是时长 | 想再次避免完成后丢上下文 | 手动触发是否足够有价值 | 单页状态机 + 20 秒模拟 |
| 2. **Agent Sidecar** | 贴在 Codex/Claude/Cursor 旁的桌面伴随层 | 多 Agent 用户；同时跑两个任务 | 每个 Agent 一条 checkpoint 轨道，完成时对应轨道亮起 | 为人机交接而生，不是专注控制 | 多任务时少一次找回上下文 | Web 无法真正置顶和读取外部应用 | 浏览器双任务 sidecar 原型 |
| 3. **Return Protocol** | 一种跨 Agent 的开源 checkpoint/complete/return 事件协议 | 工具开发者；为 Agent 加回流能力 | adapter 发标准事件，客户端保存最小上下文 | AI 工具碎片化需要共同协议；不含计时/奖励 | 集成越多，个人连续性越强 | 冷启动和生态依赖 | TypeScript adapter 接口 + mock |
| 4. **Drift Rescue** | 发现自己飘走时的一键救援入口 | 高分心创作者；已经在刷网页 | 按“我飘走了”，确认目的，得到最小下一步 | 训练恢复而非封锁离开 | 失败后仍能回，不破 streak | 用户偏航时想不起工具 | 全局页面按钮 + reroute 流程 |
| 5. **Attention OS** | 系统级管理 Active/Waiting/Recovery/Return 的状态层 | 重度 AI 工作者；跨应用工作 | 菜单栏切状态，系统通知/快捷键接回 | 人机协作带来新 OS 状态；不是效率 Dashboard | 所有工具共享同一回流节律 | 权限、跨平台、开发成本极高 | 浏览器内状态引擎模拟 |
| 6. **Blank Interval** | AI 运行时主动清空信息输入的反信息流空间 | 容易刷短视频的用户；20–90 秒等待 | 选择留白，完成时只出现下一步 | AI 等待是新型空白；不屏蔽、不种树 | 想获得一次真正不被填满的间隙 | 价值可能被误解为白噪音/冥想 | 留白动效 + 完成信号 |
| 7. **Cognitive Savepoint** | 像保存游戏一样保存“我做到哪、下一步” | 知识工作者；任何计划性中断 | 一击存档，稍后从相同上下文 respawn | 现代工作中断频繁；目标不是累计分钟 | 少一次重读/找文件 | 容易退化为书签或待办 | 快捷 checkpoint + 恢复卡 |
| 8. **Return Bell** | 无界面的声音回流器 | 不想看屏幕的创造者；短等待 | 说出下一步，完成时用个性化两声提示并复述 | 语音/Agent 可用性提升；不要求留在 App | 更低摩擦、更少屏幕 | 浏览器录音权限、环境打扰 | 手动文本 + Web Speech 可选原型 |
| 9. **Task Estuary 河口** | 把多个 Agent 输出汇聚到一个人类接管点 | 同时管理 3+ Agent 的开发者 | 输出到达同一“河口”，按意图与优先级接回 | Agent 并发让输出等待人类接管 | 减少错过与上下文冲突 | 需要真实多工具集成 | 3 条模拟任务轨道 |
| 10. **Body Bridge** | 用身体微动作桥接脑内等待与工作回归 | 久坐低能量用户；长任务运行 | 选 20 秒远眺/伸展，动作结束保留原 checkpoint | AI 释放了短恢复窗口；不是健身/冥想 App | 身体更舒服且能继续工作 | 不能验证动作真实性，医疗边界 | 3 个单次微动作，不做课程 |
| 11. **Return Practice** | 专门训练“从中断回来”的能力，而非保持不动 | 学生/知识工作者；模拟中断训练 | 不同间隙后回忆下一步，看到个人恢复趋势 | AI 时代恢复能力比封锁更重要 | 感知自己越来越会回来 | 训练与真实工作脱节 | 三轮实验模式 |
| 12. **Relay 跨设备接力** | 电脑离开前保存，手机只承载微行动，电脑完成后接回 | 多设备 Agent 用户；离开座位等待 | 电脑交棒、手机恢复、电脑接棒 | AI 任务跨时间运行；不是手机使用限制 | 外出也不会丢任务 | 同步、账号、隐私与通知成本 | 仅画协议，暂不进入 MVP |

## 概念对比

- 最能 30 秒展示差异：Return Gate、Drift Rescue、Cognitive Savepoint。
- 最强长期壁垒：Return Protocol、Agent Sidecar、Attention OS。
- 最强跨场景迁移：Cognitive Savepoint、Return Practice、Body Bridge。
- 最容易重新变成普通工具：Blank Interval（冥想化）、Body Bridge（健康课程化）、Cognitive Savepoint（待办化）。
- 最值得先实现：**Return Gate**，内部以 **Return Protocol** 建模，提供 **Drift Rescue** 作为第二入口。
