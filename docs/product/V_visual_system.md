# V｜视觉与交互系统

## 核心语言

墨流不再使用「暖纸、绿植、计时圆环」的专注产品通用语法。新版是石墨黑、骨白和信号橙构成的注意力连续性仪器。

## 签名动作

一条横线代表当前认知线程：

- Idle：完整，但尚未封存；
- Waiting / Drift：左右退开，中央出现真实空档；
- Return：两端向中央脉冲；
- Active：线重新连续。

`prefers-reduced-motion` 下不播放重合动画，状态仍通过形态和文字表达。

## 层级

- 大标题：窄体、极大字号，只表达当前状态；
- 橙色：只表示信号、接回和选中；
- 边框：代替卡片阴影，保持工业编辑感；
- 底部 Context Dock：每个状态只给一条规则型建议；
- 桌面左轨 / 移动底栏：历史与设置始终可达。

## 无障碍

- 所有主动作可键盘操作并有可见 focus ring；
- 跳到主要操作链接；
- 状态通知使用 `role=status` / `aria-live`；
- 设置与欢迎层使用 dialog 语义；
- 颜色之外仍有文字、结构与形态；
- 390px 起响应式单列布局，按钮保持触控面积。
