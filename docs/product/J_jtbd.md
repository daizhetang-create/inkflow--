# J — 第一用户的真实任务（JTBD）

第一用户：高频使用 Codex、Claude Code、Cursor 或其他 Agent 做 Web/Vibe Coding 的个人创造者。

## 共同任务结构

- **功能任务**：在 Agent 异步执行时保存足够上下文，并在完成后用最小成本继续。
- **情绪任务**：不因为短暂离开而自责，也不在回来时面对“我刚才在干什么”的空白。
- **身份任务**：成为能与 AI 稳定协作、掌握自己注意力的人，而不是被更快工具切得更碎的人。
- **隐性阻力**：任何超过一句的记录都会被认为比“直接拿手机”更麻烦。
- **最怕失去**：刚刚形成的判断、下一步和对整个系统的心智模型。
- **最小胜利**：AI 完成后 30 秒内完成第一步，并主观确认上下文回来了。

## 8 个真实场景

### 1. 20 秒小修改

- **触发**：让 Agent 改一段 CSS，预计很快。
- **当前行为**：下意识切微信/短视频，回来后又读一遍 diff。
- **期望**：按一下“AI 开始了”，输入“看移动端 390px 是否溢出”；完成时直接看到这句。
- **体验后自然语言**：“刚才差点点开别的，但它把我要检查的那一处留住了。”

### 2. 五分钟构建

- **触发**：Agent 在安装依赖、构建或跑测试。
- **当前行为**：开多个网页，五分钟变成二十分钟。
- **期望**：选择留白/远眺，构建结束时用下一步回到终端。
- **自然语言**：“这五分钟真的休息了，而且回来没断。”

### 3. Agent 失败

- **触发**：命令报错或权限失败。
- **当前行为**：先烦躁，再重新读完整日志，忘记原本目标。
- **期望**：完成信号标注“手动/模拟失败”，仍把“先确认错误是否与目标相关”还给用户。
- **自然语言**：“它没有装作成功，也没让我从头来。”

### 4. 同时跑两个 Agent

- **触发**：一个改前端，一个查部署。
- **当前行为**：结果到达顺序改变后不知道先接哪个。
- **期望**：每个 session 有稳定 checkpoint；先接回最早/主动选择的一条。
- **自然语言**：“我能看见哪条线在等我，不用靠脑子顶着。”

### 5. 自己发现已经偏航

- **触发**：刷网页两分钟后突然意识到离开任务。
- **当前行为**：羞愧、关页面、再磨蹭一会儿。
- **期望**：点击“我飘走了”，确认目的是否仍然，按一击 respawn。
- **自然语言**：“它没骂我，只问我还回不回那件事。”

### 6. 页面刷新/浏览器崩溃

- **触发**：开发服务器或浏览器刷新。
- **当前行为**：临时状态消失，靠历史记录拼回上下文。
- **期望**：return packet 从本机恢复，明确数据没有上传。
- **自然语言**：“页面没记住我的代码，但记住了我下一步要做什么。”

### 7. 阅读中断迁移

- **触发**：读研究资料时接电话。
- **当前行为**：回来从段首重读，找不到刚才的问题。
- **期望**：保存“回来看作者如何定义 resumption lag”，回来时同样接回。
- **自然语言**：“原来这不是程序员工具，它保存的是我的注意力方向。”

### 8. 低能量回流

- **触发**：深夜 Agent 完成，脑子已经钝。
- **当前行为**：看见通知但不想面对结果，继续刷屏。
- **期望**：低能量模式先给“打开结果，读最后一句”，随后再揭示完整下一步。
- **自然语言**：“它没有催我变高效，只让我先迈回去一步。”
