# Q — 不可妥协质量线

## 理解与首用

- [ ] 首屏 10 秒内能说出：这是在 AI 等待后帮我接回任务的工具。
- [ ] 不看教程，30 秒内完成一次 20 秒模拟闭环。
- [ ] 首屏只出现一个主决定，不出现统计/设置/功能卡堆。
- [ ] 每个状态只有一个视觉主语与一个主动作。

## 机制诚实

- [ ] manual、simulation、adapter 来源始终可见。
- [ ] 页面隐藏不等同 drift，通知送达不等同 return。
- [ ] 不出现“AI 已检测到”除非真实 adapter 提供证据。
- [ ] 不以专注分钟为北极星，不使用伪个性化建议。

## 视觉与动效

- [ ] 不沿用暖纸、墨绿、书本圆环、茶室/冥想风和通用 AI 渐变。
- [ ] 不用大型圆角卡片组成 Dashboard。
- [ ] signature interaction 只表达封存、间隙与接回。
- [ ] 所有动效有 reduced-motion 等价路径；装饰动画可删而不损害理解。
- [ ] 桌面优先呈现 Agent 等待，移动端变为伴随/接回，不做等比例缩放。

## 可访问性与交互

- [ ] 单一 `h1`、逻辑标题、完整键盘路径、清晰 focus-visible。
- [ ] 状态变化用适度 `aria-live`；不每秒朗读倒计时。
- [ ] dialog/overlay 有焦点管理、Escape、背景 inert 与返回焦点。
- [ ] 触摸目标 ≥44px，文本对比 WCAG AA。
- [ ] 低能量模式减少信息与检索挑战，不用降低字号/对比。

## 可靠性与隐私

- [ ] 刷新、离线、通知拒绝、多标签页和计时后台化均有降级。
- [ ] localStorage 有 schemaVersion、解析保护和迁移入口。
- [ ] 不自动保存 Prompt/代码/URL；一键清空。
- [ ] 构建、lint、自动测试和真实浏览器核心流程全部通过。
- [ ] 任何未实现能力在 UI、文档和晨报中一致标注。
