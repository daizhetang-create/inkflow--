# L — “愿意回来”的伦理行为循环

## 循环 A：封存—间隙—接回（主循环）

1. **触发**：Agent 开始执行或用户即将离开。
2. **极小行动**：写/确认一行“回来第一步”。
3. **即时奖励**：上下文被压成清晰 checkpoint，心理上允许离开。
4. **间隙**：拉取一个微行动或选择留白。
5. **上下文恢复**：完成时先看自己的下一步，按“接回”。
6. **情绪反馈**：“这次在 18 秒内接回”，不评价好坏。
7. **能力成长**：更会写可执行 checkpoint，回流延迟和主观恢复逐步改善。
8. **失败重返**：没回来时保留 checkpoint，下次直接 respawn，无断签惩罚。

优点：因果最完整、AI 场景最清楚。风险：若等待完成信号不可靠，体验需要手动结束或诚实模拟。

## 循环 B：察觉—重算—第一步（偏航救援）

1. **触发**：用户意识到已经偏航。
2. **极小行动**：按“我飘走了”。
3. **即时奖励**：界面移除非必要内容，只问“目的还一样吗”。
4. **上下文恢复**：保留 intent，重算比原 checkpoint 更小的 next action。
5. **情绪反馈**：“偏航不是失败，回来就是动作。”
6. **长期成长**：缩短从察觉到第一动作的时间。

优点：无需外部集成，跨场景强。风险：用户偏航时不一定记得打开墨流；未来需要快捷键/浏览器扩展。

## 循环 C：回忆—揭示—校准（回流训练）

1. **触发**：长间隙后返回。
2. **极小行动**：先尝试说出下一步，或选择“给我线索”。
3. **即时奖励**：揭示 checkpoint，感到“我重新接上了”。
4. **上下文恢复**：做第一动作。
5. **长期成长**：通过低频提取练习提高上下文自我恢复能力。

优点：研究依据强，能从工具变成能力训练。风险：疲劳时像考试；默认只在长间隙/用户启用时出现，低能量模式跳过。

## 选择

MVP 使用 A 为主，B 为始终可达的第二入口，C 作为可关闭实验。反馈只展示最近一次具体事实与个人节律，不做 streak、积分、等级、排行榜或无限回流历史。

## 伦理边界

- 产品的成功是用户离开墨流回到真实任务，不是 session 时长或页面停留。
- 不使用连续签到、损失厌恶、红色失败、社交比较、虚假稀缺和高频通知。
- 用户未响应时提醒指数退避并最终静默。
- 所有自动检测标明来源与不确定性。
- 不把一般分心描述为疾病，不作 ADHD、焦虑或成瘾治疗承诺。
- 允许清空全部本地记录、关闭节律记忆和只使用无记录模式。
