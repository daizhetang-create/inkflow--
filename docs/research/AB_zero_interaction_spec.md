# 墨流 0.6：清零重建交互说明

## 这次否定了什么

0.5 的问题不是配色或细节，而是先建立“设计氛围”，再让用户寻找操作。页面拥有明显的视觉概念，却没有把日常最常发生的动作压缩到足够直接。

0.6 不继承以下界面结构：

- 左侧导航栏或底部多标签导航；
- 首页仪表盘；
- 主卡片与次级卡片的堆叠；
- 圆形计时器；
- 墨迹、宣纸、植物、冥想等隐喻；
- 首屏同时展示计划、专注、记录和洞察。

旧版本仍由 Git 历史保留，但不会进入当前应用入口。

## 唯一主交互

打开墨流，用户只完成一句话：

> 从「现在 / 某个时间」开始，留「多少分钟」，只做「一件具体的事」。

这句话本身就是表单，不再先打开弹窗，也不要求先理解应用的信息架构。

两种结果：

1. 选择「现在开始」：提交后立即进入计时；
2. 选择「排到稍后」：提交后进入今天的安排。

## 状态转换

### 未开始

- 页面主体是时间句子；
- “现在开始”是默认选择；
- 时长选择会即时改变页面中的蓝色时间束；
- 今天的安排位于右侧第二层，不抢占主动作。

### 正在进行

- 输入界面整体退出；
- 页面只保留任务名称、剩余时间、线性进度、暂停和完成；
- 不出现统计、建议或其他导航；
- 下一项计划只显示为一行“接下来”。

### 暂停

- 计时数据保留；
- 主动作由“暂停”变为“继续”；
- 用户仍可完成当前一段。

### 完成

- 当前一段进入今日记录；
- 页面自动回到时间句子；
- 输入焦点回到“只做什么”。

## 副交互

今天的安排是唯一副层：

- 桌面端固定在右侧；
- 移动端通过右下角“今天”打开底部层；
- 正在计时时，可以从今日层安排下一段；
- 删除、开始等行内操作不进入主界面。

## 视觉原则

- 冷灰工作台，而不是纸张；
- 黑色代表确定动作；
- 电蓝色只代表时间、进行状态和可继续的路径；
- 不使用情绪化插画；
- 不使用大面积玻璃、渐变、阴影或圆角卡片；
- 主要动态只有时间束长度、计时进度和状态切换。

## 产品判断

0.6 的目标不是一次定义墨流的最终赛道，而是先建立一个可以每天真实使用、几乎不需要学习的核心动作。未来的注意力记录、智能建议与共同创作机制，只能围绕这条主交互生长，不能重新占据首屏。
