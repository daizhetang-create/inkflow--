# 墨流原生感 UI 重构研究

日期：2026-07-31

## 当前界面问题

现有版本功能完整，但视觉语法更像“被装进圆角外壳的网站仪表盘”，而不是用户每天愿意反复打开的 App：

- 首屏同时出现标题、主卡片、统计、时间流、同步和多处按钮，主操作不够唯一。
- 桌面端用大面积双栏卡片表达信息，像 dashboard；移动端只是压缩同一结构。
- 大量圆角容器、描边和装饰性背景争夺注意力，内容层级依赖“卡片套卡片”。
- 次要操作长期暴露，用户在准备开始一件事时仍需扫描过多控件。
- 底部导航、顶部栏、主内容的材质与层级接近，缺乏原生 App 中“内容层”和“控制层”的区分。

## 参考产品与可迁移原则

### Things 3

来源：https://culturedcode.com/things/features/

- 强大功能通过渐进披露隐藏在任务详情中，主列表保持安静。
- 动画用于解释对象如何展开、归位，而不是单纯装饰。
- Today 是每日唯一入口，不把用户先送进总览 dashboard。

迁移：墨流默认只突出“此刻/下一段”，计划详情和删除等操作降低视觉优先级。

### Tiimo

来源：https://www.tiimoapp.com/

- 把抽象时间转成可以看见、可以跟随的纵向时间线。
- 倒计时直接服务开始、切换和维持，而不是作为独立工具存在。
- 以一个清楚的下一步减少执行冻结。

迁移：把今日计划重组为一条“墨线”，当前段是墨线上的唯一高对比节点。

### Flighty

来源：https://developer.apple.com/news/?id=970ncww4

- 关键信息始终放在最前面，并借用现实世界中早已被理解的机场信息牌。
- 状态变化发生时，信息层级自动变化；异常状态比普通状态更醒目。
- 设计目标是“明显到近乎无聊”，不要求用户解释界面。

迁移：计时状态、任务名称和剩余时间成为主舞台；同步、统计、设置退到控制层。

### iA Writer

来源：https://ia.net/writer/

- 专注不是增加元素，而是主动淡化与当前动作无关的内容。
- 正在处理的句子保持清晰，其他内容仍存在但退后。

迁移：计时开始后，周围界面降低对比度，核心任务和时间保持视觉锋利。

### Gentler Streak

来源：https://docs.gentler.app/release-notes-and-announcements/a-more-intuitive-streak

- 把“此刻最相关”的内容动态放到顶部，并主动减少标签数量。
- 反馈围绕个人状态与恢复，不制造比较压力。

迁移：墨流不使用连续签到、排名或惩罚性红色；完成是一段时间被收好，而不是被打分。

### Opal

来源：https://opalapp.com/help/what-are-sessions

- Session 是完整行为单元，开始前只暴露完成这次会话所需的必要选择。
- 约束强度和临时退出属于次级设置，而不是主界面常驻信息。

迁移：开始/暂停/完成是恒定主交互，其余动作只在相关状态出现。

### Apple Human Interface Guidelines 与 Apple Design Awards

来源：

- https://developer.apple.com/design/human-interface-guidelines/layout
- https://developer.apple.com/design/human-interface-guidelines/sheets
- https://developer.apple.com/design/awards/2025/

- 内容应延伸到屏幕边缘，导航和控制浮在内容层之上。
- 关键信息应拥有足够空间，次要内容采用渐进披露。
- Sheet 只承载与当前上下文紧密相关的一项任务。
- 优秀交互应贴合平台、直觉化并能以极少控制完成复杂任务。

## 本轮确定的视觉方向

名称：**Quiet Monument / 安静纪念碑**

不是仿 iOS，也不是继续做东方风格仪表盘。它是一块全屏、克制、有重量的“今天”：

- 主色：骨白、近黑、单一朱砂橙；不依靠多彩卡片区分层级。
- 字体：系统无衬线负责操作与数字，中文衬线只用于品牌和极少量情绪标题。
- 签名动作：一条连续的“墨线”穿过当前段与今日时间流，计时开始后墨线缓慢推进。
- 桌面端：左侧窄导航轨道 + 全屏内容，不再模拟一台带圆角边框的设备。
- 移动端：顶栏 + 内容 + 悬浮底部导航，遵守安全区；主 CTA 保持在拇指可达区域。
- 新建计划：单一底部 Sheet，填写任务、时间、时长后立即回到今天。
- 动效：对象展开、状态推进、按钮按压三类；不加入无意义漂浮和炫光。

## 不采用的方向

- 不复制 Apple 的 Liquid Glass 外观。
- 不做通用 SaaS dashboard。
- 不把所有功能做成圆角卡片。
- 不让数据统计与核心任务争夺首屏。
- 不依赖插画掩盖信息架构问题。
