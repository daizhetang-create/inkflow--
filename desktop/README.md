# 墨流个人桌面版

这不是产品概念页，而是一款只服务个人日常节奏的 Windows 应用。它可以离线运行，关闭主窗口后留在系统托盘，让计时与提醒继续工作。

## 当前闭环

- 25 / 45 / 60 分钟专注，也可以写下这一段只做什么。
- 专注自然结束或手动完成后，自动进入设定时长的休息。
- 工作中间与睡前各一次冥想，可分别设置时间和分钟数。
- 根据早餐、午餐、晚餐时间，在饭后设定的分钟数提醒用药；未记录时会再提醒一次。
- 服药、冥想与晚间回顾都能在“今天”中完成或稍后处理。
- 晚间回顾记录今天完成了什么、还有什么没做、今天的结果。
- “记录”保留最近七天的专注分钟、段数与日常完成情况。
- Windows 原生通知、系统托盘、单实例运行和可选的开机自动运行。

## 直接使用

`release/Inkflow-0.8.0-Setup.exe` 是安装版；`release/Inkflow-0.8.0-Portable.exe` 是免安装版。第一次打开会先设置专注、三餐、两次冥想与回顾时间。

开机自动运行默认关闭。完成首次设置后，可从右上角设置中打开；只有应用在运行时，系统提醒才会出现。

当前是未购买代码签名证书的个人构建。Windows 可能在第一次打开时显示 SmartScreen 提示；这不影响离线运行，但正式公开发布前应补充代码签名。

个人数据保存在 `%APPDATA%/墨流/inkflow-personal.json`，不上传网络。用药时间请始终以医生或药师给出的安排为准，应用只负责提醒和记录。

## 本地构建与验证

```powershell
npm.cmd install
npm.cmd run desktop:test
npm.cmd run lint
npm.cmd run desktop:dist
```

桌面端源码位于 `desktop/`。`desktop:dist` 会生成安装版、免安装版和解压运行目录。
